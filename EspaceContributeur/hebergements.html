Hotels

1. Campamento Adán (ou Alfredo)

Type : Campement d'expédition / Refuge de jungle Prix par nuit : Compris dans le forfait global du trek (compter environ 1 860 000 COP / ~420 € pour un trek complet de 4 jours tout compris : transport 4x4, guide, repas et nuits en campement). Services inclus : Dîner, nuit en hamac ou lit superposé avec moustiquaire, douches et toilettes partagées, accès aux bassins naturels de la rivière. Adresse / Site web : Situé le long du premier tronçon de randonnée après le départ d'El Mamey ; réservable via les agences officielles agréées (ex: Expotur, Howlanders ou Ecolombia). Note / Étoiles : Non classé (hébergement de type écotourisme communautaire rustique). Image :

2. Cabaña Wiwa (Campement 2)

Type : Campement indigène géré par la communauté Wiwa Prix par nuit : Inclus dans le tarif global du trek de la Cité Perdue. Services inclus : Pension complète (petits-déjeuners, déjeuners, dîners), literie de base (lits ou hamacs avec moustiquaires), eau purifiée, électricité limitée (générateur le soir), baignade dans le río Buritaca. Adresse / Site web : Vallées de la Sierra Nevada de Santa Marta ; réservations obligatoires via les agences de trek basées à Santa Marta. Note / Étoiles : Non classé (confort rudimentaire axé sur l'immersion culturelle). Image :

3. Campamento Paraíso Teyuna (Campement 3)

Type : Campement de haute étape (le plus proche du site archéologique) Prix par nuit : Inclus dans le forfait du trek de Ciudad Perdida. Services inclus : Dîner et petit-déjeuner, lits ou hamacs abrités sous des structures en tôle/bois avec moustiquaires, espaces communs pour les repas, sanitaires collectifs. Adresse / Site web : À proximité immédiate des sentiers menant aux 1 200 marches de Teyuna. Note / Étoiles : Non classé (standard d'expédition). Image :

4. Campamento Mumake

Type : Refuge et aire de repos de la vallée Prix par nuit : Inclus dans le circuit officiel. Services inclus : Repas chauds préparés par des cuisiniers locaux, collations de fruits frais, lits en dortoir ouvert ou hamacs protégés, postes de recharge pour appareils électroniques (selon disponibilité de l'énergie solaire/groupe). Adresse / Site web : Sur le chemin de retour ou d'ascension selon la variante du parcours (3, 4 ou 5 jours). Note / Étoiles : Non classé. Image :
